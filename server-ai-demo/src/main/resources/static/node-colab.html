Dán kết quả từ Colab

Dán hai dòng URL và TOKEN mà ô chạy server trên Colab in ra. Dán nhiều lần chạy cùng lúc thì mỗi cặp vào một ô. Nội dung dán được xóa ngay sau khi điền.

Chưa nối Server AI. Bạn vẫn dán và sắp xếp được các node, rồi sao chép dạng .env. Muốn kiểm tra và lưu, hãy kết nối ở phía trên.

Các endpoint Server AI mà trang này gọi 
GET    {API}/web/ai/nodes            → danh sách 5 node: name, url, enabled, hasToken, status, inFlight, ...
PUT    {API}/web/ai/nodes/{name}     ← { url, token?, enabled, maxConcurrency }   (bỏ token = giữ token cũ)
DELETE {API}/web/ai/nodes/{name}
POST   {API}/web/ai/nodes/check      ← { url, token }  → { reachable, authorized, latencyMs, error? }
GET    {API}/web/ai/overview         → { queueLength, nodes[] }       (gọi mỗi 3 giây)
POST   {API}/web/ai/tasks            ← { taskType: "nl_search", query } hoặc "question_check" + ID + nội dung
POST   {API}/web/ai/tasks/burst      ← { count }
GET    {API}/web/ai/tasks            → 30 task mới nhất
