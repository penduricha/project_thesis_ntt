Các endpoint Server AI Worker mà trang này gọi 
GET    {API}/web/ai/nodes            → danh sách 5 node (kèm modelDigest, runtimeVersion, tokensPerSec)
PUT    {API}/web/ai/nodes/{name}     ← { url, token?, enabled, maxConcurrency }
DELETE {API}/web/ai/nodes/{name}
POST   {API}/web/ai/nodes/check      ← { url, token }
GET    {API}/web/ai/overview         → { queueLength, model, promptVersion, questionCheckMode, nodes[] }
GET    {API}/web/ai/issue-types      → danh mục 5 nhãn lỗi chuẩn + none
POST   {API}/web/ai/tasks            ← { taskType: "nl_search" | "question_check", ... }
POST   {API}/web/ai/tasks/burst      ← { count }
GET    {API}/web/ai/tasks            → 30 task mới nhất (kèm analysis + suggestions + span_start/span_end)
GET    {API}/web/ai/tasks/{id}/status→ đọc nhanh trạng thái từ Redis
  • 5 nhãn chuẩn của question_check: spelling, grammar, logic, distractor, key_doubt (và none khi sạch).
  • Khi chạy độc lập trên ntt_demo_llm (không khóa ngoại), không cần điền questionId/questionRevisionId.
